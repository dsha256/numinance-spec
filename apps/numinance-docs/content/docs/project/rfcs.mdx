RFCs are in `numinance-spec/rfcs/`. A change beyond `contract-additive` needs one, open for comment at least 14 days. The template `0000-template.md` has these sections: Status (draft, open, accepted or rejected), Author, Opened, Change class (`contract-additive`, `contract-breaking` or `protocol`), Problem, Proposal, Alternatives, Compatibility and migration, Security considerations and Open questions.

The specification lives in the public [numinance-spec](https://github.com/dsha256/numinance-spec) repository. This site does not state a separate contribution channel.

What `GOVERNANCE.md` says about taking part:

1. Contributions use the Developer Certificate of Origin: sign off each commit (`Signed-off-by`). There is no CLA.
2. Changes beyond `contract-additive` go through an [RFC](/docs/project/rfcs), open for comment at least 14 days.
3. Contributions are under Apache-2.0. See [License](/docs/project/license).
4. Adapters can be checked with the [conformance](/docs/integrations/conformance) kits.

Read [Governance](/docs/project/governance) first.

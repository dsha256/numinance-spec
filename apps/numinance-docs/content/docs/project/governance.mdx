In summary, `GOVERNANCE.md` states:

- **License.** Everything in the repository is Apache-2.0, including its patent grant. Numinance commits not to relicense released versions of the protocol, SDKs, conformance kits, CLI or official adapters under a more restrictive license.
- **Changes.** A change beyond `contract-additive` goes through an RFC in `rfcs/`, open for comment for at least 14 days before acceptance. See [RFCs](/docs/project/rfcs).
- **Contributions.** They use the Developer Certificate of Origin (`Signed-off-by`). There is no CLA.
- **Trademarks.** "Numinance", "Numinance Verified" and "Numinance Conformant" are trademarks. Their use is governed by a `TRADEMARKS.md` that `GOVERNANCE.md` says is to be published with the registry. That file and `MAINTAINERS.md` are not in the checkout this site was written against.
- **Decisions.** They are made by the maintainers listed in a `MAINTAINERS.md` until a neutral foundation is considered, which GOVERNANCE.md plans once three or more external vendors ship adapters.

Governance covers the public spec only. The proprietary runtime is not governed by this process. Compatibility follows [Versioning](/docs/project/versioning).

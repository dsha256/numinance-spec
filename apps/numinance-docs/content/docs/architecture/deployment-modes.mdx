## Data residency

Each executor and model pair declares its compute and inference location, prompt egress, training use and retention. A residency class is derived from live configuration, not copied from a static manifest, and compared with the policy floor for the component and environment when a change starts. Regulated components default to in-account inference in-region; cross-region use is an explicit opt-in. Being on a cloud provider or a hosted model service is never assumed to mean in-account. Resolver and reviewer inference obey the same floor as author inference.

## Credential handling without secrets in the sandbox

The sandbox starts with no ambient credentials, keys or tokens. A step receives a handle; the egress proxy applies the credential outside the sandbox and re-originates the request. Handles expire with the step. Providers that require materialised secrets are flagged for security review and policy approval.

## Security model summary

| Threat | Control |
| --- | --- |
| Prompt injection through retrieved content | Content treated as data; broker, proxy and filesystem enforce regardless |
| Credential theft | No ambient credentials; scoped, expiring handles |
| Metadata service access | Link-local addresses denied |
| Malicious extension | Signing, digest pinning, permission diff, conformance |
| Policy tampering | Protected paths, kernel outside every grant |
| Evidence forgery | Runner-only writes, append-only store |
| Direct deploy | Release identity only |
| Cost runaway | Multi-dimensional budgets, pause and escalate |

Numinance is designed to produce evidence that supports a customer's compliance program. It does not make anyone compliant.

## Observability and evaluations

Telemetry follows OpenTelemetry conventions and is exported to the customer's own backend. It carries identifiers, decision and run references and metrics, and never secrets, handles, prompts, retrieved knowledge or customer code. Evaluations use the event stream and outcomes as a private customer corpus to compute qualification for promotion. That corpus stays in the customer account and is not a shared training set.

## Failure cases

- Residency below floor at start: change refused.
- Control plane outage in managed mode: authorised work continues.
- Telemetry sink down: events buffer locally; evidence writing is independent.

# schema

Standard-library JSON Schema 2020-12 validator for the kind schemas in `../../../schemas/gen/`. Public so that every loader of kind documents validates with the same code. `Compile` a schema once; `Validate` a value decoded with `json.Decoder.UseNumber`; any other keyword fails `Compile` with `ErrUnsupported`; a failure is a `*ValidationError` listing each `Violation` (path and keyword). Tests: `go test ./sdk/go/schema` from `numinance-spec/`.

| Keyword | Behaviour |
| --- | --- |
| `$schema` | must be draft 2020-12; also accepted below the root, where the generator emits it, without starting a new resource |
| `$id` | root only (a nested `$id` would move `$ref` resolution) |
| `$ref` | `#` or `#/...` to a schema in the same document; no percent-encoding, anchors or other documents |
| `type` | name or array of names; `integer` matches any number with an integral value (`1.0`, `1e2`) |
| `properties`, `additionalProperties`, `required` | `additionalProperties: false` reports an unknown field; neither may sit beside `$ref` |
| `enum` | strings, booleans and null |
| `minimum`, `maximum` | inclusive, numbers only, compared exactly; a bound of magnitude 10^(2^39) or more, or its reciprocal, fails `Compile` with `ErrUnsupported` |
| `pattern` | Go `regexp` (RE2), unanchored, strings only, limited to the subset where RE2 and ECMA-262 with the `u` flag match alike: printable ASCII, escapes `\d \D \w \W \b \B \t \n \r \f \v` and escaped punctuation, `(?:`, classes without `[` inside, `{` only to start `{n}`, `{n,}` or `{n,m}`; an unescaped `}` or `]` outside a class, `.`, `\s`, `\A`, `\Q`, `\p`, flags, lookaround and backreferences fail `Compile` with `ErrUnsupported` |
| `items` | one schema for every element (no `prefixItems`) |
| `anyOf` | non-empty; a failure reports `anyOf` only, not the branches |
| `propertyNames` | each key as a string; a failure reports the key's path |
| `title`, `description`, `format` | annotations, not asserted |

Every other keyword fails `Compile` with `ErrUnsupported`, among them `allOf`, `oneOf`, `not`, `if`, `const`, `prefixItems`, `contains`, `patternProperties`, `unevaluated*`, `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`, the length and count keywords, `$anchor`, `$dynamicRef`, `$comment` and `default` (`TestCompile_FailClosedKeywords`).

Numbers: a `json.Number` is read in place against the RFC 8259 grammar and compared digit by digit, never through `float64` or `math/big`; exponents saturate at 2^40, so beyond 10^(2^40) two numbers compare by their digits alone. A `float64` is read in its shortest round-trip form. Bounds: `MaxDepth` on schema nesting and on the longest `$ref` chain, cycles rejected; `MaxVisits` on how many subschemas (`$ref`, `anyOf` branches) can check one value; so work per value depends on the schema, never on the value. `MaxViolations` per call; `MaxPathBytes` per path. `Compile` measures the schema with recursion at most `MaxDepth` deep, so a long `$ref` chain fails with `ErrDepth` without a deep stack (`TestCompile_LongRefChainStack`); a `$ref` cycle longer than `MaxDepth` also fails with `ErrDepth`, a shorter one with `ErrCycle`. Before any schema check, `Validate` walks the whole value without recursion into a tree that holds each object's sorted keys and each parsed number, so the up to `MaxVisits` checks of one value sort and parse nothing and build a child path only when they use it (`TestValidate_VisitsDoNotAllocate`); the tree costs about 64 bytes per value, plus about 48 per number, plus the spare capacity of a growing slice; a value outside the JSON data model (another Go type, an invalid `json.Number`, NaN, an infinity) is a `type` violation wherever it sits, also in an array without `items`, and the schema is then not checked; so is an array or object nested `MaxValueDepth` deep, and the container whose children would take the walk past `MaxValueNodes` values (a Go value that holds or shares itself), counted before they are added, so the tree never holds more than `MaxValueNodes` values (`TestValidate_SharedWideValue`). Work per value is linear in its size times up to `MaxVisits`, about 650 times the decode cost in the worst case (1.8 s for a 200 KB object), so the kind loader must size-limit every value before `Validate`. Violations never carry values; `Violation.Path` is built from untrusted keys, so readers quote it (`Error` does). A path over `MaxPathBytes` is cut at a character boundary (a key of invalid UTF-8 may be cut back to its start), never inside a `~0` or `~1` escape, and ends in `~`, which no JSON Pointer ends in; values below a cut path report the same cut path. Duplicate keys are not detected (`encoding/json` keeps the last); the loader rejects them before validating.

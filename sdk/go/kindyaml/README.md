# kindyaml

Loads and writes the configuration kinds of `numinance.kinds.v1` as YAML. Public so that the Engine, the `numi` CLI and third-party tools read kind documents with the same code.

`NewLoader` compiles the embedded schema of every kind (`../../../schemas/embed.go`) and refuses a kind whose envelope does not have the expected types (`metadata` a `numinance.kinds.v1.Metadata`, `spec` a message, `extensions` a `map<string, google.protobuf.Value>`). `Loader.Decode` runs four stages in order and stops at the first failure; each error wraps one sentinel and never quotes a value of the document; a schema violation names its path, which is built from the document's keys (an unknown key among them) and quoted. A `Loader` is immutable and safe for concurrent use.

| Stage | Refuses | Error |
| --- | --- | --- |
| Size | more than `MaxBytes` (128 KiB) | `ErrTooLarge` |
| YAML | not one YAML document, text that is not UTF-8 (the parser refuses it); only the line of the parser error is kept, since some go-yaml messages quote the document | `ErrSyntax` |
| | more than one document, a root that is not a mapping, anchors, aliases, merge keys (`<<`), explicit tags (the non-specific tag `!` leaves no trace on the parsed node and is ignored), a key that is not a string, a boolean other than `true`/`false`, a number not in RFC 8259 form (`0x10`, `1_000`, `+1`, `.inf`, `.nan`) | `ErrUnsupported` |
| | a key twice in one mapping | `ErrDuplicateKey` |
| | nesting deeper than `MaxDepth` (64; the root mapping is level 1) | `ErrDepth` |
| | more than `MaxNodes` (16384) values: mappings, sequences and scalars other than mapping keys | `ErrTooManyNodes` |
| Schema | a missing or unknown `kind`, one that names a message that is not a kind (no `api_version`), or a produced kind (ContextBundle), which Numinance builds and never loads as configuration (the error names the kind) | `ErrKind` |
| | the kind's generated JSON Schema (unknown fields among others), then protojson (a duration that is not `7200s` form) | `ErrSchema` (wraps `*schema.ValidationError` from the first) |
| Loader checks | `apiVersion` other than `APIVersion`, `kind` other than the message name, `metadata` or `spec` missing, a `metadata.name` that is empty, over `MaxNameBytes` (253) or has a control character (`unicode.IsControl`), U+2028, U+2029 or a bidi mark, embedding, override or isolate (U+061C, U+200E, U+200F, U+202A to U+202E, U+2066 to U+2069), a zero enum value anywhere in a numinance message (an implicit-presence enum, a set optional enum, a list element or map value), an empty field named in `requiredFields` (a repeated field left empty, an implicit-presence field left zero or a singular message field left unset, such as an ArchitecturePack rule without `check`), a key of a map field named `extensions` at any depth that is not reverse-DNS (the `plugin_id` rule: two or more dot-joined labels matching `^[a-z]([a-z0-9-]*[a-z0-9])?$`, at most 253 bytes); SDLCProfile `playbooks`, `control_packs`, `architecture_packs` and `toolchains`; ControlPack `sources`, `controls` by id, `export_views` by name, and each control's `requires_evidence` and each view's `controls`; a `ttl` not above zero, a `retention_max` or `cache_ttl` below zero, and a `max_concurrent`, `calls_per_stage`, `bytes_per_call`, `required_approvals` or model `max_context` of 0 | `ErrInvalid` |

Added in a later minor of the kinds. `ResidencyPolicySpec.training_use` is an optional enum under `FORBID`: an absent value means `TRAINING_USE_FORBIDDEN`, so a consumer never reads absence as permission; the zero value and any unknown name are refused, and `TRAINING_USE_ALLOWED` is accepted only in an org-scoped document. `StageGate.required_approvals` is an optional count of distinct approving principals, 1 or more when present (absent means 1), and is refused (`ErrInvalid`) on a gate whose kind is not `GATE_KIND_HUMAN` (only a human gate counts approvals; the effective count is the largest of the gate, the policy `approvers.count` and a control pack approval floor, decided outside the loader); it never relaxes approver != author, which the policy decision enforces. `KnowledgeConnectionSpec.oauth` is an optional `{client_id}` under `FORBID`: the client id is 1 to 2048 bytes of printable ASCII, and one that starts with a scheme (`name:`) or `//`, or holds a backslash or `%`, or contains `://` or a colon before its first `/`, `?` or `#`, is read as a URL and must pass the endpoint rule (a plain id has no colon before its first `/`); a `.` or `..` path segment is refused; there is no secret field, since the broker holds secrets. `PlaybookSpec.rollout` (since 1.2.0, `MERGE_DIRECTIVE_REPLACE`) is optional: absent means the playbook defines no rollout and the release stops at Releasing for a human. When present it names `staging` and `production` (different, lower-case letters, digits and hyphens, 1 to 63 bytes), 1 to 8 `stages` of unique lower-case names with `weight` 1 to 100 rising strictly and ending at 100, and a `window` of 1 minute to 24 hours (`ErrInvalid` otherwise; the JSON Schema covers shape only). The release context validates the plan again (`releasewire.RolloutPlanOf`). The loader does not read `training_use` or the counts; the profile context and the policy decision do. `ttl` above zero, `read_only` true, non-empty `regions` and the org-only `floors` are unchanged and pinned again in `additive_kinds_test.go`.

`Lockfile` (design section 8, `.numinance.lock.yaml`, since 1.1.0) pins installed extensions and knowledge tool inventories; the install flow writes it. Loader checks: each `extensions[]` entry has an `id` (a plugin_id: at least two dot-joined labels of lowercase letters, digits and hyphens, at most `MaxExtensionIDBytes` (253) bytes), a strict x.y.z `version`, `digest` and `permissions_digest` as sha256 digests, `h1` ("h1:" plus the standard base64 of 32 bytes), `zh` ("zh:" plus 64 lowercase hex characters) and a `signer` (one printable line of at most `MaxSignerBytes` (1024) bytes with no space); `extensions` are unique by `id` and `knowledge_tools` unique by connection and name; a tool's `connection` and `name` are names (`isName`) and its `hash` a digest. Both lists may be empty. `YAMLToJSON` exposes the YAML dialect (no anchors, aliases, merge keys, tags or duplicate keys, bounded size, depth and nodes) for documents that are not kinds, such as the `manifest.yaml` of an extension package.

Alpha kinds. `EvalSet` (RFC-0004, ADR 0047) is a pre-GA kind at `apiVersion: numinance.dev/v1alpha1`. `NewLoader()` refuses it with `ErrAlpha` (which wraps `ErrKind`), and `Encode` does the same; `NewLoader(WithAlphaKinds())` reads and writes it, and then accepts only `v1alpha1` for it and only `v1` for every other kind. Only a composition root that runs an alpha feature passes the option; `numi validate --files` passes it so the examples are checked. The loader checks of `EvalSet` are: `spec.version` a strict x.y.z version; a case `name`, an expected `layer` and a seeded `defect` or `caught_by` a token (1 to `MaxTokenBytes` (64) bytes of lowercase ASCII letters, digits and `. _ -`, starting with a letter or digit); each `outcome.value` a digest; `acceptance` and `category` not their zero value; a layer `count` of at least 1; 1 to `MaxEvalCases` (256) cases sorted by name without duplicates; expected layers sorted without duplicates; a `seeded` case has a `category`; a case of category planted security bug or migration hazard is `seeded`; a `seeded` case expects the change not accepted, not merged and not severe, with its `caught_by` layer among its expected failures. A case holds no free text: tokens, enums, counts and digests only. An EvalSet takes no part in profile resolution.

A YAML 1.1 timestamp such as `2026-10-18` is read as the string it was written as. Decoding into a `yaml.Node` never expands aliases, so an alias bomb is refused before it grows. The YAML parser stops at its own limit of 10000 levels and the loader's recursion at `MaxDepth`. The 128 KiB cap is what bounds the validator's work (its README: up to about 650 times the decode cost); `MaxNodes` bounds the values the loader converts and the validator visits below that.

`Loader.Encode` writes a kind message as block YAML in field order with the schema's keys, from protojson with `EmitDefaultValues` (never `EmitUnpopulated`, whose nulls the strict schema rejects). It refuses a nil message or one that is not a kind of the loader (`ErrKind`) and runs the loader checks first (`ErrInvalid`). It builds the YAML tree from the protojson tokens and double-quotes the string `<<` and any string with a rune outside YAML's printable set, a tab or a line break other than `\n` (U+0085, U+2028, U+2029), so `Decode(Encode(m))` equals `m` for any `m` that passes the checks.

This loader refuses documents the first loader accepted (a zero enum value, an empty required field, a non-reverse-DNS `extensions` key, an unsafe `metadata.name`, more than `MaxNodes` values). Since a later change it also refuses a `FORBID` field or residency `regions` in a document that does not claim `SCOPE_ORG`, which an AutonomyPolicy or ResidencyPolicy at repo scope could set before, and an AdapterSelector `provider`, `instance` or `knowledge` name that is not ASCII segments, which the name rule accepted before. The tightening lands before the first tag of `numinance-spec`, so no released consumer depends on the looser behavior. A document that decodes has no authority by decoding: `metadata.scope` is the document's own claim, and the profile context gives a policy kind, a ControlPack or an SDLCProfile authority only when it was loaded from a protected path or a signed policy bundle.

A kind change that adds a repeated field the loader must keep non-empty, an implicit-presence field it must keep non-zero or a field with presence it must keep set (a message or an optional scalar) adds its full name to `requiredFields` in `loader.go`, and a value rule to `valueChecks` or a uniqueness key to `uniqueKeys`; `TestRequiredFields_NameFields`, `TestValueChecks_NameFields` and `TestUniqueKeys_NameFields` fail on a name that does not resolve to such a field.

Tests: `go test ./sdk/go/kindyaml` from `numinance-spec/` (one failing case per refused construct and per loader check, the `MaxBytes`, `MaxDepth` and `MaxNodes` boundaries, errors not quoting the document, the `Encode` round trip, zero list elements and map values through a dynamic message, and each kind's required fields and enums against its example in `kinds_test.go`). Fuzz with `go test ./sdk/go/kindyaml -run '^$' -fuzz '^FuzzDecode$'` (seeded from the examples) and `-fuzz '^FuzzEncode_RoundTrip$'`. `go test ./schemas` decodes every example.
